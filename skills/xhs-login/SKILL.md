# 小红书自动化登录

## 技能概述
本技能调用本地自动化脚本 `login.py`，可以通过自动化脚本帮助获取登录二维码并发送给用户扫码。如果当前已经处于登录状态，则直接发送当前的屏幕截图以确认登录成功。

## 触发条件
当用户的输入包含但不限于以下意图时，应当触发本技能：
- 明确要求“登录小红书”或“扫码登录小红书”。
- 需要获取小红书登录二维码。
- 确认当前小红书账号是否在线或登录是否失效。

**示例触发话术：**
- “帮我登录小红书。”
- “发个小红书登录二维码给我扫一下。”
- “测试一下小红书账号现在是不是登录状态。”
- “运行小红书登录脚本。”

## 核心工具与使用案例 (CLI Tool)

该技能依赖本地 Python 脚本 `login.py` 进行登录状态的管理和页面操作。

### 基本使用 (Basic Usage)
直接运行该脚本以触发登录流程：
```bash
python ./login.py
```
*(注：请确保脚本路径与当前文件所在目录相同)*

## 执行流程说明 (Execution Flow)

1、脚本运行后，会检查当前登录状态。
2、若未登录或状态失效（需要扫码），则会截取登录二维码并发送给用户进行扫码。
3、若已登录且状态有效，则会直接发送当前的屏幕截图以确认登录成功。
