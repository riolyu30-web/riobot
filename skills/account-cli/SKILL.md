# Account CLI

## 技能概述
本技能用于处理日常记账相关请求，分为两类场景：

- `记录`：记录一笔收入或支出。
- `统计`：按时间范围汇总账单，并按用户要求给出概括或进一步分析。

当用户提出“记一笔支出”“登记收入”“查看本月账单”“统计最近一周收入支出”“分析这段时间花销”这类需求时，应优先调用本技能。

## 工作流

### 一、记录工作流
1. 先判断用户是否提供了账单图片、收据图片、转账截图或其他可识别图片。
2. 如果有图片，先调用 `read_image` 提取账单信息，重点识别：
   - 金额
   - 收支类型
   - 描述或用途
   - 日期
3. 如果没有图片，则直接使用用户文本中提供的账单信息。
4. 如果无法得到完整且可执行的记账信息，必须提示用户补充；至少需要：
   - 收支类型：`收入` 或 `支出`
   - 金额
   - 描述
   - 日期可选，未提供时默认为今天
5. 根据意图选择命令：
   - 收入场景调用 `income`
   - 支出场景调用 `expense`
6. 可直接参考以下命令模板：

```bash
python {homespace}\tools\\account\\cli.py expense <amount> "<description>"
```

```bash
python {homespace}\tools\account\cli.py expense <amount> "<description>" --date YYYY-MM-DD
```

```bash
python cli.py income <amount> "<description>"
```

```bash
python cli.py income <amount> "<description>" --date YYYY-MM-DD
```
8. 返回简洁明确的结果给用户，至少包含：
   - 记录类型
   - 金额
   - 描述
   - 日期
9. 如果工具执行失败，直接反馈失败原因，并提示用户修正金额、日期或描述信息。

### 二、统计工作流
1. 先识别统计时间范围。
2. 如果用户没有明确给出时间范围，默认使用`当前月`。
3. `当前月`默认解释为：从本月第一天到今天。
4. 将时间范围整理为 `YYYY-MM-DD` 格式的开始日期和结束日期。
5. 可直接参考以下命令模板：

```bash
python {homespace}\\tools\\account\\cli.py ledger --start-date YYYY-MM-DD --end-date YYYY-MM-DD
```
7. 从结果中提取并优先返回概括信息：
   - 记录数
   - 总收入
   - 总支出
   - 净额
8. 如果用户提出进一步需求，再按要求做分析，例如：
   - 哪天支出最多
   - 收入与支出趋势
   - 某类描述的高频消费
   - 某个时间段的收支对比
9. 如果没有记录，直接明确告知用户该时间范围内没有交易记录。

## 参数提取规则

### 记录场景
- `amount`：必须是可解析的数字金额。
- `description`：优先使用用户原话中的用途、项目、商品或备注。
- `txn_date`：若用户未提供，则使用当天日期；若提供，则规范化为 `YYYY-MM-DD`。
- `type`：根据用户表达判断为 `income` 或 `expense`。

### 统计场景
- `start_date`：统计开始日期。
- `end_date`：统计结束日期。
- 若用户表达为自然语言时间，如“今天”“本周”“本月”“上个月”，先换算成明确日期范围。

## 缺失信息时的处理
- 缺少金额时，必须追问金额。
- 缺少收支类型且无法从上下文判断时，必须追问是收入还是支出。
- 缺少描述时，必须追问这笔账的用途或说明。
- 图片识别结果不可靠或字段缺失时，不要强行入账，先向用户确认后再调用工具。

## 示例触发语句
- “记一笔支出，午饭 23 元。”
- “今天收入 800，客户回款。”
- “把这张小票记到账里。”
- “帮我统计本月收入和支出。”
- “看一下最近七天账单，并分析下花销。”
