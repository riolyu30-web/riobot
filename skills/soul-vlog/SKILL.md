# Soul Vlog (图文画册生成)

## 功能
输入用户需求与参考图片，生成动态、瞬间、朋友圈的图片与文案。

## 工作流程
本技能需要严格按照以下步骤执行：

### 1. 分析需求与确定框架
深入分析用户的写作要求与核心意图，确定以下画册元数据：
- **用户需求**：用户需求描述，例如“我想写一个关于我的工作经历的动态”。
- **搭配的文案**：结合人设与用户需求，在网上搜索并阅读相关内容（如热门文案、相关背景知识、风格参考等），以此为基础构思图文内容。
- **画册标题**：确定一个符合主题的 HTML 文件名（例如 `XX.html`）。
- **图片尺寸**：根据发布平台和风格，选择合适的尺寸（可选：`1024x1024`, `1024x1536`, `1536x1024`, `2048x2048`, `2048x1152`, `3840x2160`, `2160x3840`）。

### 2. 合并参考图片
- **最终参考图片**：如果用户提供了参考图片路径，通过以下命令将其与用户个人图片合并，获得最终参考图片。否则，直接使用用户个人参考图片路径。
 ```bash
python {homespace}\\tools\\imagecli\\cli.py merge <用户个人图片路径> <用户参考图片路径>
```

### 3. 逐一调用工具生成
根据拆解好的规划，逐一通过 Python 命令行调用 `imagecli` 工具获取**结果图片路径**。
**命令格式示例**：
```bash
python {homespace}\\tools\\imagecli\\cli.py create --prompt “以参考图右侧人物作为主体，把人物放进参考图左侧场景中，换上高档服饰，人物的肢态要自然舒展，切记不要正对镜头。模仿手机拍摄效果，保持人物的自然感和真实感。”+"<用户需求>" --description "<搭配的文案>" --size <图片尺寸> --html-name <画册标题> --image <最终参考图片>
```
*注：务必保持 `--html-name` 在同一批次生成中一致，这样它们才会被追加到同一个 HTML 画册页面中。*

- 判断是否返回“调用API成功”，则继续执行下一步，否则提示用户图片生成失败。

### 4. 返回查看链接
- 确保生成任务被触发后，等待大概1分钟，通过以下命令检查图片是否已完成下载：
```bash
python {homespace}\\tools\\imagecli\\cli.py check <结果图片路径>
```
- 图片已完成下载，最后将图片通过 message 工具返回给用户。
- 如果超过5分钟仍未完成下载，提示用户图片生成失败。
