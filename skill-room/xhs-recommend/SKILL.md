# 小红书热搜话题查询

## 技能概述
本技能调用本地自动化脚本 `recommend.py`，可以通过自动化脚本帮助获取指定关键词在小红书平台的热搜话题、热门笔记及相关推荐内容，并将结果整理后返回给用户。

## 触发条件
当用户的输入包含但不限于以下意图时，应当触发本技能：
- 明确要求“查询小红书热搜”或“搜索小红书话题”。
- 需要获取某个特定关键词（如“美妆”、“旅游攻略”等）在小红书上的热门推荐。
- 分析当前小红书平台上某领域的热度趋势。

**示例触发话术：**
- “帮我查一下小红书上关于‘露营’的热搜话题。”
- “现在小红书上‘咖啡’相关最火的笔记有哪些？”
- “获取小红书‘穿搭’关键词的推荐内容。”
- “运行小红书热搜查询脚本。”


### 基本使用 (Basic Usage)
直接运行该脚本并传入需要查询的关键词以触发查询流程：
```bash
# 运行小红书热搜查询脚本并传入关键词参数
python ./recommend.py --keyword "关键词"
```
*(注：请确保脚本路径与当前文件所在目录相同)*

## 执行流程说明 (Execution Flow)

1、脚本运行后，解析用户传入的关键词参数。
2、调用相关接口或自动化操作页面，搜索该关键词下的热搜话题。
3、把话题分类，每个类型提取最有可能成为热门的话题（如写出3-5个标题），并格式化输出返回给用户。
