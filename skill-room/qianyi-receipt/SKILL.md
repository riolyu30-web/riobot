# 千亿面料明细码单生成

## 技能概述
本技能专门用于为“千亿面料”生成标准化的明细码单凭证图片。当用户需要针对特定的面料生成交易凭证或明细单时，系统将通过调用本地专用的 CLI 工具来进行处理，将商品数据（货名、颜色、米数、单价等）绘制成一张排版整齐的图片凭证（PNG格式）。

## 触发条件
当用户的输入包含但不限于以下意图时，应当触发本技能：
- 需要为某款或多款面料生成码单、凭证、报价单或收据图片。
- 提供了面料的交易明细（如品名、颜色、米数、单价），要求制作并输出单据。
- 明确要求“打印”或“生成”一张千亿面料的凭证。

**示例触发话术：**
- “帮我生成一份码单，包含802面料，3号色，米数分别是5, 6, 7.5米，单价10元。”
- “制作一份收据图片，货名是蚕丝字母条，红色，10米和15米，单价12.5。”
- “把刚刚查到的这款面料生成一张明细单给我。”

## 核心工具与使用案例 (CLI Tool)

该技能依赖本地 Python 脚本 `receipt.py` 进行凭证生成。它接收用户提供的商品数组（JSON格式字符串），并输出包含这些商品明细的图片凭证文件。

### 基本使用 (Basic Usage)
直接传入包含单款面料明细的 JSON 字符串：
```bash
python receipt.py --items '[{"model": "802", "color": "#3", "meters": [5, 6, 7.5], "unit_price": 10.0}]'
```

### 多商品生成 (Multiple Items Usage)
支持在 JSON 数组中传入多个商品对象，以生成包含多行数据的码单：
```bash
python receipt.py -i '[{"model": "802", "color": "#3", "meters": [5, 6, 7.5], "unit_price": 10.0}, {"model": "蚕丝字母条", "color": "红", "meters": [10, 15], "unit_price": 12.5}]'
```

## 命令行参数说明 (Command Line Options)

| 参数 (Option) | 类型 (Type) | 必填 (Required) | 默认值 (Default) | 描述 (Description) |
| :--- | :--- | :--- | :--- | :--- |
| `--items` / `-i` | `TEXT` (JSON字符串) | **是 (Yes)** | 无 (None) | JSON 格式的商品数组字符串。每个商品对象需包含 `model` (货名/品号), `color` (颜色), `meters` (米数数组或逗号分隔的字符串), `unit_price` (单价) 等字段。 |
| `--output` / `-o` | `TEXT` | 否 (No) | 自动生成 (Auto) | 指定输出的图片路径。若不传，则默认保存在脚本同级目录的 `image` 文件夹下。 |

## 数据返回说明 (Output Description)

执行成功后，工具将在控制台输出标准化的 JSON 字符串，包含以下结构：
```json
{
  "status": "success",
  "message": "生成成功",
  "file_path": "C:\\develop\\nanobot\\skill-room\\qianyi-receipt\\image\\receipt_XXXXXXXXXXXXXX.png"
}
```

生成的图片凭证包含以下结构化信息：
- **头部**：凭证标题（明细码单凭证）、公司名称（千亿纺织）及地址、制单日期及单号。
- **表格区**：各商品的货名、颜色、每卷米数（最多支持单行显示10个卷数）、总数量、单价及金额明细。
- **底部**：总数量、本单应收合计、收款大写金额及备注申明等。
