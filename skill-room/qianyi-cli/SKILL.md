# 千亿面料信息查询

## 技能概述
本技能专门用于查询和获取“千亿面料”的详细产品信息及报价。当用户提出需要查询特定面料的属性、价格或特性时，系统将通过调用本地专用的 CLI 工具库来进行精确或模糊匹配，并返回结构化的产品数据。

## 触发条件
当用户的输入包含但不限于以下意图时，应当触发本技能：
- 查询某款面料的价格（纯白单价、彩色单价、版布价）。
- 检索某款面料的物理属性（如：门幅、克重、空差、成分等）。
- 询问特定“品号”（Product No）或“品名”（Product Name）的面料详细信息。
- 需要获取千亿面料产品的特性描述。

**示例触发话术：**
- “帮我查一下 801# 面料的报价和成分。”
- “千亿面料里有没有 802 这款？克重和门幅是多少？”
- “我想了解一下涤天丝（曲天丝）的详细信息和单价。”

## 核心工具与使用案例 (CLI Tool)

该技能依赖本地 Python 脚本 `product.py` 进行数据检索。它接收用户提供的面料品号（支持部分匹配和模糊搜索），并返回详细的产品结构化数据（JSON 格式）。

### 基本使用 (Basic Usage)
直接传入需要查询的面料品号：
```bash
python product.py "801"
```

### 多品号查询 (Multiple Products Usage)
支持同时传入多个品号或品名字符串进行批量检索：
```bash
python product.py "801" "涤天丝"
```

## 命令行参数说明 (Command Line Options)

| 参数 (Option) | 类型 (Type) | 必填 (Required) | 默认值 (Default) | 描述 (Description) |
| :--- | :--- | :--- | :--- | :--- |
| `product_nos` | `TEXT[]` (多值) | **是 (Yes)** | 无 (None) | 想要查询的面料品号列表（如 `"801"`, `"802"`）。脚本会基于这些值对面料编号和名称进行模糊匹配。 |

## 数据返回说明 (Output Description)

执行成功后，工具将输出包含面料对象的 JSON 数组。为了易读性，返回对象的属性名已处理为中文，解析时请参考以下字段：

- `品号`: 面料编号
- `品名`: 面料名称
- `特性`: 面料特性描述
- `纯白单价`: 纯白面料价格
- `彩色单价`: 彩色面料价格
- `版布价`: 样板布价格
- `成分`: 面料材质成分表（包含材质名称和百分比）
- `门幅`: 面料宽度
- `克重`: 面料每平方米重量
- `空差`: 长度偏差或损耗指标
